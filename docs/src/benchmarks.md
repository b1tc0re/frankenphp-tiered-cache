# Бенчмарки

Taskfile содержит Go-бенчмарки для `MemoryCache`:

- `task bench:get` сравнивает чтение по одинаковым и разным ключам.
- `task bench:cleanup` измеряет фоновую очистку и её влияние на `Get`/`Set`.
- `task bench:memory` собирает замеры учёта памяти, Go heap и RSS процесса.

Для сравнения изменений запускайте замеры на одной машине и при одинаковой
нагрузке. Абсолютные значения зависят от конфигурации и текущей нагрузки хоста.
